FOOTBALLZONE WEBSITE

Files:
- index.html: page structure and content
- style.css: colors, layout, responsive design
- script.js: mobile menu, match filters, demo newsletter form

HOW TO OPEN:
1. Extract the ZIP file.
2. Open the footballzone folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.

NOTES:
- Match cards are sample fixtures, not live match data.
- The newsletter form is a front-end demo and does not send or store email addresses.
- Google Fonts requires an internet connection; the site otherwise uses fallback fonts.
